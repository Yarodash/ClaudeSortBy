# ClaudeSortBy

Пункт **«Отсортировать по…»** в контекстном меню Проводника Windows. Кликаешь по
папке или диску, пишешь любой запрос — метрику («по важности», «по тому, что
можно удалить без сожаления») или вопрос («где тут могут быть пароли?») — и
Claude ранжирует содержимое, а в браузере открывается отчёт: сетка с превью,
дерево, звёзды, причины и ответ на вопрос.

Кнопка 🎲 подставляет случайную метрику из `metrics.json` (файл можно править).
Галочка «Рекурсивно» разрешает Claude самому решать, в какие подпапки заглянуть.

## Приватность

Claude **не получает доступа к файловой системе**: все инструменты явно
запрещены. Python сам сканирует папку и отправляет модели только имена и
метаданные (тип, размер, даты, количество вложенных элементов, разрешение
картинок). Содержимое файлов модель не читает и выйти за пределы выбранной
папки не может.

## Требования

- Windows 10/11.
- [Claude Code CLI](https://claude.com/claude-code) — установлен и залогинен
  (`claude` в PATH). Каждая сортировка — один-несколько вызовов модели haiku.
- Для запуска из исходников: Python 3.10+ (с галочкой «Add to PATH»);
  опционально `pip install pillow` (превью картинок).
- Опционально: `ffmpeg` в PATH (превью видео): `winget install Gyan.FFmpeg`.

Релизный `ClaudeSortBy.exe` самодостаточен — Python и Pillow внутри, отдельно
ставить не нужно.

## Установка

### Вариант 1 — релиз (рекомендуется)

1. Скачай `ClaudeSortBy-win64.zip` со [страницы релизов](../../releases) и распакуй
   в постоянную папку (например `C:\Tools\ClaudeSortBy`) — пути прописываются в
   реестр, потом не перемещай.
2. Запусти `install-with-claude.cmd` — Claude сам установит пункт меню, проверит
   реестр и починит проблемы. Либо вручную:
   `powershell -ExecutionPolicy Bypass -File install.ps1`
3. Если SmartScreen ругается на exe: ПКМ → Свойства → «Разблокировать».

### Вариант 2 — из исходников

```powershell
git clone https://github.com/Yarodash/ClaudeSortBy.git
cd ClaudeSortBy
powershell -ExecutionPolicy Bypass -File install.ps1
```

`install.ps1` сам определяет раскладку: если рядом есть `ClaudeSortBy.exe` —
регистрирует его, иначе `pythonw.exe sortby.pyw`. Пишет только в HKCU,
админ-права не нужны.

## Использование

ПКМ по папке, фону папки или диску → «Отсортировать по…» (в Windows 11 —
внутри «Показать дополнительные параметры», или Shift+F10). Ввести запрос →
ОК → отчёт откроется в браузере.

## Если что-то сломалось

Открой Claude Code в папке ClaudeSortBy и скажи:

> прочитай FIX.md и почини установку ClaudeSortBy

В [FIX.md](FIX.md) — чеклист диагностики: реестр, пути, Claude CLI, типовые
поломки и лечение. Тот же файл использует `install-with-claude.cmd`.

## Удаление

`powershell -ExecutionPolicy Bypass -File uninstall.ps1`

## Сборка релиза

`powershell -ExecutionPolicy Bypass -File build.ps1` — соберёт
`release/ClaudeSortBy-win64.zip` (PyInstaller, onefile, windowed).

## Как устроено

| Файл | Роль |
|---|---|
| `sortby.pyw` | GUI-окно ввода метрики (tkinter) |
| `scan.py` | Сканирование папки: имена + метаданные, с бюджетом времени |
| `engine.py` | Вызовы `claude -p` (haiku, JSON-схема, все инструменты запрещены); обычный и рекурсивный режимы |
| `report.py` | HTML-отчёт: сетка/дерево, лайтбокс с зумом |
| `thumbs.py` | Превью картинок (Pillow) и видео (ffmpeg) с кэшем в `%LOCALAPPDATA%` |
| `metrics.json` | Метрики для кнопки 🎲 |
| `install.ps1` / `uninstall.ps1` | Регистрация/удаление пункта меню (HKCU) |
| `install-with-claude.cmd` | Автоустановка силами Claude Code |
| `FIX.md` | Инструкция для Claude по установке и починке |

# FIX.md — инструкция для Claude по установке и починке ClaudeSortBy

Этот файл читает Claude (Claude Code), когда его просят установить ClaudeSortBy
в контекстное меню или починить сломанную установку.

Если ты Claude и пользователь сказал что-то вроде «прочитай FIX.md и почини
установку ClaudeSortBy» — следуй этому документу сверху вниз.

## Что такое ClaudeSortBy

Пункт «Отсортировать по…» в контекстном меню Проводника Windows для папок,
фона папки и дисков. При клике открывается окно ввода метрики, затем Claude CLI
(модель haiku, headless) ранжирует содержимое папки по свободному запросу, и в
браузере открывается HTML-отчёт.

Две раскладки:
- **Релиз**: в папке лежит `ClaudeSortBy.exe` — самодостаточный exe (Python внутри).
- **Исходники**: в папке лежит `sortby.pyw` — нужен Python 3.10+ (`pythonw.exe` в PATH).

Обязательная зависимость в обоих случаях: **Claude Code CLI** (`claude` в PATH
или `%USERPROFILE%\.local\bin\claude.exe`), залогиненный в аккаунт.

## Шаг 1. Установка

1. Определи папку ClaudeSortBy (папка, где лежит этот FIX.md).
2. Запусти из неё PowerShell-скрипт: `powershell -ExecutionPolicy Bypass -File install.ps1`
3. Скрипт сам выбирает режим (exe или pythonw) и пишет три ключа в HKCU (админ-права не нужны).

## Шаг 2. Проверка установки

Проверь, что созданы все три ключа и их команды указывают на существующие файлы:

```powershell
$keys = "HKCU:\Software\Classes\Directory\shell\ClaudeSortBy",
        "HKCU:\Software\Classes\Directory\Background\shell\ClaudeSortBy",
        "HKCU:\Software\Classes\Drive\shell\ClaudeSortBy"
foreach ($k in $keys) { (Get-ItemProperty "$k\command" -ErrorAction SilentlyContinue).'(default)' }
```

Ожидаемый вид команды (одно из двух):
- `"C:\...\ClaudeSortBy.exe" "%1\."` (релиз)
- `"C:\...\pythonw.exe" "C:\...\sortby.pyw" "%1\."` (исходники)

Важно: аргумент должен заканчиваться на `\."` — хвост `\.` обходит баг Windows
с бэкслэшем перед кавычкой у корня диска (`D:\`). Не «исправляй» его.

## Шаг 3. Функциональный тест

1. Проверь Claude CLI: `claude --version`. Если не найден — проверь
   `%USERPROFILE%\.local\bin\claude.exe`. Если нигде нет — скажи пользователю
   установить Claude Code (https://claude.com/claude-code); без него ничего не заработает.
2. Создай временную папку с парой файлов и запусти утилиту вручную:
   - релиз: `.\ClaudeSortBy.exe <путь-к-временной-папке>`
   - исходники: `pythonw sortby.pyw <путь-к-временной-папке>`
   Должно открыться тёмное окно «Отсортировать по…». Это GUI — не жди
   завершения процесса, просто проверь, что процесс жив через пару секунд и
   не упал. Потом убей его.
3. Напомни пользователю: в Windows 11 пункт находится в «Показать дополнительные
   параметры» (Shift+F10 или Shift+ПКМ).

## Типовые поломки и что с ними делать

| Симптом | Причина | Лечение |
|---|---|---|
| Пункта нет в меню | Ключи не записаны | Перезапусти install.ps1, проверь ключи из Шага 2 |
| Пункт есть, но клик молчит | Команда указывает на несуществующий путь (папку переместили) | Перезапусти install.ps1 из НОВОГО расположения папки |
| Пункт есть, клик молчит, пути верные | `pythonw` не в PATH у Проводника | Переустанови Python с «Add to PATH», перелогинься, снова install.ps1 |
| Окно открывается, но «Claude не ответил» | Claude CLI не найден / не залогинен / нет сети | `claude --version`, `claude -p "ping"` — диагностируй; можно задать путь через переменную окружения `CLAUDESORTBY_CLAUDE` |
| Ошибка выполнения .ps1 | ExecutionPolicy | Запускай через `powershell -ExecutionPolicy Bypass -File install.ps1` |
| SmartScreen блокирует exe | Неподписанный exe из интернета | ПКМ по exe → Свойства → «Разблокировать», или `Unblock-File ClaudeSortBy.exe` |
| Нет превью видео | ffmpeg не в PATH | Опционально: `winget install Gyan.FFmpeg`, перелогиниться |
| Окно с ошибкой «Путь не найден» на корне диска | Кто-то убрал `\.` из аргумента в реестре | Верни аргумент `"%1\."` (см. Шаг 2) |

## Удаление

`powershell -ExecutionPolicy Bypass -File uninstall.ps1` — удаляет три ключа HKCU.
